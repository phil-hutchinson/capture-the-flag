# Peer Review — 00000034 Rule Change: Diagonal Attack and Board Sizing

## Summary

This branch publishes major 2 of the ruleset across five documents: the notation
becomes size-parametric, diagonal attack enters the baseline rules, `PRE-RELEASE`
is retired in favour of two parallel rulesets (`2-0:BATTLE`, `2-0:SKIRMISH`), and
`BOARD_LAYOUT` / `ARMY_COMPOSITION` become the first two published variants. An
edition is redefined as a major baseline plus a complete set of flag values,
dropping piece distribution as a separate axis. The change is documents-only by
design; no code is touched.

**Static checks:** `pyright` reports **0 errors, 0 warnings, 0 informations**.
`ruff check .` reports **All checks passed!** Neither is meaningful evidence here,
since the branch contains no Python changes — they are recorded for completeness.

**Reference documents:** `story.md` is present and was read. **There is no
`implementation-plan.md`** — the developer explicitly waived it and asked for
direct implementation. See issues 8 and 9, which are raised for the record rather
than as a criticism of that decision.

**Story conformance:** the five documents the story named are all changed as
specified, and `proposed-variants.md` is untouched as the story required. The
substantive findings below are edge cases and prose regressions introduced during
drafting, not deviations from the story.
