# Peer Review — Story 49: Implement Ruleset Three

## Summary

The branch publishes major 3 and rewrites the rules layer to it across 20 committed
steps: the shadow documents graduate, the board/army/edition swap lands atomically,
placement is replaced by start-position generation with position IDs, and the six rule
changes (direction-relative encumbrance, open-path diagonal attack against every piece,
inverted combat, rank reduction, attrition endings, a 40-ply inactivity limit) each
arrive in their own step. `ENG_NN_4` is specified and implemented, and notation gains
`=N` and the `StartPosition` header tag. The work is well sequenced and the rules
themselves are implemented faithfully; the findings below are concentrated in the
peripheral surfaces the plan never scheduled a step for, two hot-path costs, and stale
prose the step-19 sweep missed.

**Static checks.** `pyright` — clean (0 errors, 0 warnings, 0 informations).
`ruff check .` — clean (all checks passed). `pytest` — 409 passed, 16 deselected;
`pytest -m slow` — 16 passed. No findings filed from any of these.
